# PDF-dragonTranslator
Dịch file PDF dài, tối đa 100 trang [con số thực tế là tối đa 30MB và 100K token đầu vào, số trang chỉ là ước tính tương đối], sử dụng model Argon của Gemini.

Chỉ API Key trả phí mới sử dụng được, chi phí ước tính 1000 VND/trang bản gốc; Chi phí thực tế có thể tăng giảm so với con số ước tính này.
